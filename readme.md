# Portal Acadêmico | Sistema de Atendimento e Matrículas

Aplicação front-end desenvolvida para a disciplina de Desenvolvimento Front-End (Análise e Desenvolvimento de Sistemas - Unisinos).

## Funcionalidades
- **Acesso Multi-perfil (Demo):** Visão do Aluno e Visão Institucional/Professor.
- **Gestão de Matrículas:** Consulta de ofertas por área, verificação de choque de horário no padrão Unisinos e controle de carga horária.
- **Atendimento Acadêmico:** Abertura de protocolos (dúvidas, ajuste de grade, quebra de pré-requisito) e painel institucional de resposta com indicadores de status.

## Tecnologias
- React 17 (Componentes Funcionais, `React.Component`, `state` e Context API)
- HTML5, CSS3 & Bootstrap 5 / Bootstrap Icons
- Node.js + Express (API REST local)
